## Описание

На первом этапе реализована модель данных в памяти. В ней находятся три
таблицы из ER-диаграммы: `Agent`, `Command` и `Result`. Записи представлены
именованными кортежами `NamedTuple`. Данные не сохраняются на диск.

На втором этапе добавлен удалённый вызов всех 13 операций модели по TCP.
Клиент переводит имя метода и его аргументы в бинарный запрос, сервер
выполняет метод общей модели и возвращает результат в формате JSON.

Используется только стандартная библиотека Python.

## Модель данных

Связи между таблицами:

- `Command.agent` ссылается на `Agent.key`;
- `Result.command` ссылается на `Command.key`.

Для каждой таблицы реализованы создание, удаление, получение всех записей
и редактирование. Метод `get_recent_cache` выбирает команды за последние
шесть минут, соединяет их с результатами и возвращает пары `tags` и
`cache_hit`.

## Формат RPC

Все числовые поля заголовка передаются от младшего байта к старшему.

Запрос:

| Поле | Размер |
|---|---:|
| Размер JSON-тела | 5 байт |
| Код операции | 2 байта |
| Тело в формате JSON | указанное число байт |

Ответ:

| Поле | Размер |
|---|---:|
| Размер JSON-тела | 3 байта |
| Код операции | 1 байт |
| Тело в формате JSON | указанное число байт |

Коды операций:

| Код | Метод | Код | Метод |
|---:|---|---:|---|
| 1 | `create_agent` | 8 | `update_command` |
| 2 | `delete_agent` | 9 | `create_result` |
| 3 | `get_agents` | 10 | `delete_result` |
| 4 | `update_agent` | 11 | `get_results` |
| 5 | `create_command` | 12 | `update_result` |
| 6 | `delete_command` | 13 | `get_recent_cache` |
| 7 | `get_commands` | | |

Успешное тело ответа имеет вид:

```json
{"ok": true, "result": {"key": 1, "timestamp": 1000}}
```

Ошибка передаётся так:

```json
{"ok": false, "error": "У агента 1 есть команды"}
```

Сервер печатает каждый отправленный ответ в стандартный вывод.

## Запуск этапа 2

В первом терминале запустите сервер:

```bat
run.bat
```

Сервер слушает адрес `127.0.0.1:5052`. Не закрывайте первый терминал.

Во втором терминале запустите демонстрацию:

```bat
run_demo.bat
```

Клиент удалённо вызывает все 13 методов модели:

1. создаёт, получает и изменяет агента;
2. создаёт, получает и изменяет его команду;
3. создаёт, получает и изменяет результат команды;
4. выполняет `get_recent_cache`;
5. показывает ошибку удаления связанного агента;
6. удаляет результат, команду и агента.

Сервер останавливается сочетанием `Ctrl+C`.

## Класс клиента

Класс `RpcClient` содержит методы с теми же именами, что и `DataModel`:

```python
from client import RpcClient

client = RpcClient()
agent = client.create_agent(1, 1000)
agents = client.get_agents()
```

Каждый метод открывает TCP-соединение, отправляет один запрос, получает
один ответ и закрывает соединение. Состояние данных остаётся на сервере.
